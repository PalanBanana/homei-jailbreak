# Security policy

## Scope

This policy covers vulnerabilities in HOMEI itself: its logic, data handling, build and CI configuration. HOMEI contains no exploit and does not operate on devices.

## Reporting

Use GitHub's private vulnerability reporting on this repository ("Security" tab). If that is unavailable, open an issue that says only that you have a security report, without details.

Please do not include exploit code for Apple platforms, device identifiers, Apple Account data, pairing records or personal logs. Research on Apple platform vulnerabilities belongs in the research tracker and, for new vulnerabilities, with Apple's own security reporting channel.

## What to expect

Reports are reviewed on a best-effort basis. There is no bounty.

## Related

Scam awareness: treat jailbreak tools, profiles and installers from unverified sources as malware. See [Docs/SAFETY.md](Docs/SAFETY.md).
